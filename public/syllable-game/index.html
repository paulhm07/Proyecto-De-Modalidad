      ✅ Características técnicas implementadas:
      
    
        
  • Lenguaje: Kotlin (recomendado por Google)
    • 
        
  • API mínima: 21 (Android 5.0)
    • 
        
  • 1) Generación infinita: Handler.postDelayed cada 1500ms crea un nuevo globo con posición X aleatoria y velocidad entre 3-6 px/frame (apta para niños)
    • 
        
  • 2) Movimiento vertical: loop a 33 FPS que resta Y a cada globo; los que salen por arriba se eliminan
    • 
        
  • 3) Detector de toques: setOnTouchListener en cada globo dispara animateExplosion (scale 1→1.8 + alpha 1→0 + rotación)
    • 
        
  • 4) Validación de sílabas: compara con currentSyllables[currentSyllableIndex]; si es correcta avanza, si no, reinicia el progreso
    • 
        
  • 5) Banco de 12 palabras con sílabas separadas (PLÁ-TA-NO, MA-RI-PO-SA, E-LE-FAN-TE, etc.)
    • 
        
  • 6) Distractores inteligentes: 50% de probabilidad de generar la sílaba correcta, 50% una sílaba aleatoria de otra palabra
    • 
        
  • 7) Sin MP3: ToneGenerator nativo para sonidos pop, éxito y error
    • 
        
  • 8) Vibración: patrón de 3 pulsos en errores (compatible API 26+)
    • 
        
  • 9) Gamificación: 8 rondas, 3 vidas, +10 por sílaba, +20 bonus por palabra completada
    •
